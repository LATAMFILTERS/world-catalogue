# Find ELIMFILTERS public resources

Use this skill when a visitor needs to find publicly available ELIMFILTERS technical documentation, the public catalog discovery manifest, or indexed engineering pages.

1. Read https://elimfilters.com/.well-known/ai-catalog.json for the current approved public resource inventory.
2. Read https://elimfilters.com/llms.txt for public documentation navigation.
3. Read https://elimfilters.com/sitemap-index.xml to find public sitemap documents.
4. Return source URLs and distinguish published technical information from equipment/application fitment claims.
5. Do not infer OEM equivalence, vehicle or equipment compatibility, filtering specifications, or evidence status from a code match. If evidence is absent, state that compatibility is unverified.
6. Do not access private CRM tools, unpublished databases, admin routes, or authentication systems.

This skill provides public-resource navigation only. It has no API execution, order placement, or catalog mutation capability.
