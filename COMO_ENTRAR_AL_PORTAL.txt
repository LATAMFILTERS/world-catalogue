OPCIÓN 1: ACCESO DIRECTO EN ESCRITORIO (RECOMENDADO)
─────────────────────────────────────────────────────

1. Busca este archivo en la carpeta world-catalogue:
   → CREAR_ACCESO_DIRECTO.vbs

2. Doble-click en el archivo

3. Verás un mensaje: "✓ Acceso directo creado en el escritorio"

4. Ahora tienes un acceso directo en tu escritorio:
   → "Phase 5A - Portal Privado.lnk"

5. Doble-click en el acceso directo para abrir el portal

6. ¡Listo! El navegador abre automáticamente el portal en español


OPCIÓN 2: ABRIR ARCHIVO .BAT MANUALMENTE
──────────────────────────────────────────

1. Ve a la carpeta world-catalogue

2. Busca: PHASE5A_ACCESO_DIRECTO.bat

3. Doble-click en el archivo

4. El navegador abre automáticamente el portal


OPCIÓN 3: ABRIR MANUALMENTE EN EL NAVEGADOR
─────────────────────────────────────────────

Si ninguna de las opciones anteriores funciona:

1. Copia esta URL exactamente:
   http://localhost:3000/knowledge-system/phase5a-private?token=phase5a-victor-2026

2. Abre tu navegador (Chrome, Edge, Firefox, Safari, etc.)

3. Pega la URL en la barra de direcciones

4. Presiona ENTER


SOLUCIÓN DE PROBLEMAS
──────────────────────

❌ "La página no carga" o "Error 404"
→ El servidor de desarrollo no está corriendo
→ Solución: En PowerShell (carpeta world-catalogue):
   cd frontend
   npm run dev
→ Espera a ver: "✓ Ready in X.Xs"
→ Luego intenta acceder al portal de nuevo

❌ "Acceso Requerido" (página vacía)
→ El token no es correcto
→ Verifica que la URL sea EXACTAMENTE:
   http://localhost:3000/knowledge-system/phase5a-private?token=phase5a-victor-2026
→ Copia nuevamente la URL completa

❌ "Conexión rechazada" o "no se puede conectar"
→ El servidor no está corriendo
→ Mira arriba: "Solución: El servidor de desarrollo no está corriendo"


INFORMACIÓN IMPORTANTE

• Token: phase5a-victor-2026

¿NECESITAS AYUDA?
─────────────────

Si algo no funciona:
1. Verifica que el servidor está corriendo (npm run dev)
2. Intenta copiar/pegar la URL manualmente
3. Recarga la página (Ctrl+Shift+R hard refresh)
4. Cierra el navegador completamente y vuelve a intentar
