# Shared Engineering Knowledge

This layer stores engineering concepts once so Heavy Duty and Light Duty can reference the same validated fact without duplicating it.

## Core topics

- Filtration Efficiency
- Micron Rating
- Beta Ratio
- Dirt Holding Capacity
- Flow Rate
- Differential Pressure
- Restriction
- Bypass
- Contaminant Loading
- Media Saturation
- Sealing
- Service Life
- Installation
- Failure Analysis
- Standards

## Rule

Shared engineering knowledge may be linked to one or more application domains after validation, but it is not owned by a single industry. Domain-specific operating context belongs in the HD or LD knowledge object that references this shared concept.

## Authority boundary

Shared Engineering cannot authorize a SKU, cross reference, vehicle/equipment application or technology relationship. Those relationships must pass their corresponding governance and review gates.
