ISO 16889 specifies the multi-pass test method for evaluating the filtration performance of hydraulic and lube oil filter elements. The test circulates a contaminated fluid (ISO Medium Test Dust, ISO 12103-1 A3) through the filter element in a controlled loop, measuring particle counts upstream and downstream at defined size classes to calculate the Beta ratio (β). The Beta ratio expresses filter efficiency: β₁₀(c) = 200 means that for every 200 particles ≥10 µm entering the filter, only 1 passes through (99.5% capture efficiency). ISO 16889 superseded ISO 4572 and established the current multi-pass methodology as the global reference for filter performance classification across hydraulic, lube oil, and fuel filtration applications.

The Beta ratio derived from ISO 16889 testing is the primary technical specification used to select filtration elements that achieve target [[ISO_4406|ISO 4406 — fluid cleanliness codes]]. A filter rated β₁₀(c) = 200 under ISO 16889 test conditions will, in service, maintain fluid cleanliness near the rated code — provided flow rates, differential pressures, and contamination ingression rates stay within test parameters. In practice, ISO 16889 Beta ratios serve as the quantitative bridge between filter product specification and the measurable contamination target that protects [[PARTICLE_WEAR|equipment against particle wear]]. Without ISO 16889 certified performance data, filter selection becomes a brand-specification exercise rather than an engineering decision based on measurable contamination control capability.
