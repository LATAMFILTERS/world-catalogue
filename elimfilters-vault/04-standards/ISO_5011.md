ISO 5011 is the primary performance test standard for air intake filters for internal combustion engines. It defines the laboratory procedure for measuring three key performance parameters:

1. **Filtration efficiency** — the percentage of test dust (ISO 12103-1 A2 fine test dust, mean particle diameter 5–8 µm) captured by the filter element under controlled flow conditions
2. **Flow restriction** — the pressure drop across the filter at rated airflow, measured in kPa
3. **Dust-holding capacity** — the total mass of test dust captured before the filter reaches terminal restriction, measured in grams

These three parameters define the filtration trade-off space: a high-efficiency element with high restriction and low capacity requires frequent changes; an optimised element balances all three for the target application's dust concentration and service interval.

ISO 5011 is the basis for MACROCORE™, SYNTEPORE™, and INTEKCORE™ performance certification claims. It provides the measurement framework that converts filtration performance into comparable, auditable specifications.
