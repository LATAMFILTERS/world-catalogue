ISO 4406 is the international standard that defines the cleanliness code system for hydraulic and lubricating fluids. The standard expresses fluid cleanliness as a three-number code (e.g., 16/14/11) where each number represents a particle count range class for particles at or above three threshold sizes: ≥4 µm(c), ≥6 µm(c), and ≥14 µm(c), measured per 1 mL of fluid using automatic particle counting in accordance with ISO 4406 counting methodology. Each successive code number represents a doubling of particle count: code 16 represents 320–640 particles/1 mL; code 14 represents 80–160 particles/1 mL; code 11 represents 10–20 particles/1 mL. The suffix (c) indicates calibration against ISO 11171 standards using ISO Medium Test Dust (ISO MTD) reference particles (NIST SRM 2806).

ISO 4406 cleanliness codes serve as the measurable outcome specification for filtration system design. Equipment manufacturers specify target cleanliness codes for critical fluid circuits based on the sensitivity of internal components to particle contamination: proportional hydraulic valves (clearances 1–3 µm) typically require 16/14/11 or cleaner; engine lube circuits with journal bearings (clearances 15–50 µm) target 16/14/11 as the practical precision threshold; high-speed turbocharger bearing circuits may require 14/12/9 or cleaner. The ISO 4406 code at 19/17/14 — a common outcome with commodity filtration — represents particle counts 8× higher at the ≥4 µm class than the 16/14/11 target, directly correlating with the 3–5× reduction in bearing lifespan documented in abrasive wear studies. ISO 4406 codes are measured against [[ISO_16889|ISO 16889]] filter Beta ratios to verify that a given filtration element will achieve and maintain the target code under service conditions.
