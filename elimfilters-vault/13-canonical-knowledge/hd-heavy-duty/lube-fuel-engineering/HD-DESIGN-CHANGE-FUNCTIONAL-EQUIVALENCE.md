## Technical Relationships — Validated

- A visible design change does not by itself prove a change in fit, form or function. | status: approved
- Changes in profile, baseplate construction, thread-ring construction, drain features or element geometry require application and functional verification before equivalence is accepted or rejected. | status: approved
- Functional equivalence must be based on interface compatibility and required system behavior, not visual similarity alone. | status: approved
- A running design change must not be converted into a universal supersession rule without application scope. | status: approved

## Diagnostic Methods

- Verify sealing interfaces, threads, housing engagement, required flow path and application scope.
- Distinguish cosmetic/production changes from changes that alter functional interfaces.
