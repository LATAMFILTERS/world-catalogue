## 1. Los 5 Buyer Personas Clave

### 1.1 OPERADOR DE MAQUINARIA (Equipment Operator)

**Perfil:**
- Edad: 35–55 años
- Educación: Técnico/Secundaria
- Experiencia: 10+ años operando maquinaria (minería, construcción, agricultura)
- Responsabilidad: Operación diaria, reportar problemas
- Poder de decisión: Bajo (reporta al supervisor)

**Preocupaciones Principales:**
1. ⚠️ **Confiabilidad** — No quiero que falle mi máquina en medio de faena
2. ⏱️ **Tiempo de inactividad** — Cada hora parada es dinero perdido
3. 🛠️ **Facilidad de cambio** — Quiero un filtro que sea fácil de instalar
4. 💧 **Protección** — Que el sistema no falle por agua/arena/contaminación
5. 📞 **Soporte técnico** — Acceso a ayuda si algo sale mal

**Objetos a Superar:**
- "Nunca escuché de ELIMFILTERS, siempre usamos [marca X]"
- "¿Por qué debería cambiar si el filtro actual funciona?"
- "¿Cuánto cuesta? No tengo presupuesto para experimentos"

**Estrategia de Comunicación IA:**

```
TONO: Amigable, práctico, sin jerga técnica excesiva
PROFUNDIDAD TÉCNICA: Básica (micronaje, temperatura, duración)
ENFOQUE PRINCIPAL: Confiabilidad y protección de máquina

Estructura de respuesta:
1. PROBLEMA QUE SOLUCIONA
   "Los filtros estándar dejan pasar contaminantes que dañan 
    tus cilindros hidráulicos → costosas reparaciones"

2. BENEFICIO DIRECTO AL OPERADOR
   "Con AQUAGUARD™ tu máquina funciona más horas sin fallos
    → menos paros → más ganancias"

3. EVIDENCIA SIMPLE
   "Eficiencia 99% vs. 80% de estándar
    → 20% mejor protección"

4. LLAMADO A ACCIÓN
   "Hablemos con tu mecánico para verificar qué filtro necesitas"

PALABRAS CLAVE POSITIVAS:
✓ "confiable", "durabilidad", "protección", "rendimiento"
✗ Evitar: "nanopartículas", "adsorción", "coalescencia"
```

**Ejemplo de Diálogo:**

```
OPERADOR: "Mi excavadora consume mucho combustible"
IA: "Eso puede ser por contaminación en el sistema de inyección.
    Con SYNTEPORE™ eliminamos 99% del agua y sedimento.
    Resultado: motor más limpio, menos consumo, mejor duración.
    ¿Tu mecánico ha revisado el filtro de combustible últimamente?"

OPERADOR: "¿Cuánto cuesta?"
IA: "Menos que una reparación de inyectores (que cuesta $5,000+).
    Gastando $200 en buen filtro cada 500 horas evitas costosas fallas.
    Hablemos con tu jefe de flota para encontrar la solución correcta."
```

### 1.2 JEFE DE FLOTA (Fleet Manager)

**Perfil:**
- Edad: 40–60 años
- Educación: Ingeniería/Administración
- Experiencia: Gestión de 20–200+ vehículos/máquinas
- Responsabilidad: Mantenimiento, costo por km, disponibilidad de equipos
- Poder de decisión: Alto (aprueba especificaciones y presupuestos)

**Preocupaciones Principales:**
1. 📊 **ROI (Retorno de Inversión)** — ¿Me ahorra dinero a largo plazo?
2. 📈 **Disponibilidad de flota** — Máquinas fuera de operación = pérdida de ingresos
3. 🔧 **Mantenimiento predecible** — Intervalos de servicio claros
4. 📉 **Costos ocultos** — ¿Hay sorpresas después de la compra?
5. 🏆 **Benchmark competitivo** — ¿Cómo se compara vs. otras marcas?

**Objetos a Superar:**
- "Los costos iniciales son 20% más altos"
- "Nuestros equipos ya tienen especificaciones establecidas"

**Estrategia de Comunicación IA:**

ENFOQUE PRINCIPAL: TCO (Total Cost of Ownership), disponibilidad, riesgo

1. PROBLEMA COMERCIAL
   "Filtros estándar causan fallas: 3-5 días de inactividad/año

2. OPORTUNIDAD DE MEJORA

3. ANÁLISIS COSTO-BENEFICIO
   "Costo adicional: $200/filtro × 50 máquinas × 2 cambios/año = $20,000/año
    Beneficio: 100 días extras de operación × $5,000 ingreso/día = $500,000/año

4. RESPALDO TÉCNICO
   "Certificado ISO 4548-12, equivalente a Donaldson Ultra-Web™,

5. MITIGACIÓN DE RIESGO

✓ Costo por km/hora operativa
✓ ROI en 12 meses
✓ Referencias de flotas similares

## 3. Indicadores de Persona: Cómo Detectarla

El agente IA debe IDENTIFICAR qué persona es antes de responder:

```python
# Pseudocódigo para detección automática

def detectar_buyer_persona(mensaje_usuario):
    palabras_clave = {
        "operador": ["máquina", "falla", "parada", "excavadora", "compresor", "opera"],
        "jefe_flota": ["flota", "disponibilidad", "costo", "ROI", "volumen", "contrato"],
        "jefe_compras": ["precio", "volumen", "proveedor", "descuento", "factura", "pago"],
        "consumidor": ["mi coche", "cambio", "tienda", "instalar", "precio final", "donde compro"],
        "escéptico": ["vs ", "competitor", "donaldson", "fram", "mejor que", "garantía"]
    }
    
    for persona, keywords in palabras_clave.items():
        if any(kw in mensaje_usuario.lower() for kw in keywords):
            return persona
    
    return "generico"  # Si no detecta, responder de forma general

# Ejemplo:
msg1 = "Mi excavadora falla mucho"  → OPERADOR
msg2 = "Tengo 50 camiones en flota"  → JEFE_FLOTA
msg3 = "¿Cuál es tu mejor precio para 1000 unidades?"  → JEFE_COMPRAS
msg4 = "¿Dónde puedo comprar para mi Toyota?"  → CONSUMIDOR
msg5 = "Cómo se compara vs. Donaldson Ultra-Web?"  → ESCÉPTICO
```
