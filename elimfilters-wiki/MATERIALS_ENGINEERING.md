## 2. Familias de Materiales Filtrantes

### 2.1 Celulosa Natural y Técnica

#### Estructura Química
```
Celulosa = polisacárido linear
Unidad repetitiva: C₆H₁₀O₅ (glucosa anhídrida)

Estructura 3D:
  Cadenas paralelas ←→ enlaces hidrógeno
  Regiones cristalinas (resistentes) + amorfas (flexibles)
```

#### Características Mecánicas

| Propiedad | Valor | Influencia |
|---|---|---|
| Densidad | 1.5 g/cm³ | Baja — flota en agua |
| Resistencia a tensión | 40–100 MPa | Moderada — requiere refuerzo |
| Módulo de Young | 10–15 GPa | Semiflexible |
| Elongación a ruptura | 2–4% | Frágil en seco |
| Resistencia al rasgado | 15–25 kN/m | Moderate tearing resistance |

#### Celulosa Estándar vs. Técnica

| Aspecto | Estándar | Técnica |
|---|---|---|
| Fuente | Fibras de madera prensadas | Mezcla optimizada de fibras |
| Procesamiento | Mínimo | Blanqueado, refinado, clasificación |
| Pureza | ~95% | >98% |
| Distribución de tamaño | Heterogénea | Monodispersa (controlada) |
| Resistencia a fluidos | Limitada | Alta (compatibilidad con aceites) |
| Tratamiento | Pegante convencional | Resina fenólica/melamínica |
| Costo | Bajo | Medio |

**Implicación:** DURATECH™ (celulosa técnica) es superior a filtros de papel convencional en homogeneidad y durabilidad.

### 2.2 Celulosa Sintética (Polímeros)

#### Tipos Principales

##### Polietilén Tereftalato (PET)
```
Estructura: Poliéster aromal
Fórmula: (C₁₀H₈O₄)ₙ

Propiedades:
  • Densidad: 1.38 g/cm³
  • Temperatura de fusión: 255–260 °C
  • Resistencia a tensión: 50–70 MPa (mejorada vs. celulosa)
  • Hidrofobia: Excelente (repele agua)
  • Químicamente inerte a mayoría de aceites
```

**Uso en ELIMFILTERS:** SINTRAX™ (EL8 PERFORMANCE), parte de MICROKAPPA™ (EC1)

##### Polipropileno (PP)
```
Estructura: Polímero de propeno isotáctico
Fórmula: (C₃H₆)ₙ

Propiedades:
  • Densidad: 0.90 g/cm³ (más ligero)
  • Temperatura de fusión: 160–170 °C
  • Resistencia a tensión: 30–40 MPa
  • Hidrofobia: Excelente
  • Bajo costo relativo
```

**Uso en ELIMFILTERS:** NANOFORCE™ (nanofibra PP), BLUECLEAN™ (DEF inercia total)

##### Poliéster de Vidrio (Polyester + Glass Fibers)
```
Matriz: Poliéster insaturado
Refuerzo: Fibras de vidrio E-glass (no-alcalino)

Propiedades:
  • Densidad: 1.80–2.00 g/cm³
  • Resistencia a tensión: 50–100 MPa (fibra dominante)
  • Temperatura de servicio: hasta 180 °C
  • Inerte a combustibles, aceites, agua
```

**Uso en ELIMFILTERS:** SYNTEPORE™ (EF9, EH6), AQUAGUARD™ (ET9, ES9)

### 2.3 Fibras Inorgánicas

#### Vidrio (Borosilicato)

**Composición química:**
```
SiO₂ (silicio):      70–80%
B₂O₃ (boro):        10–15%    ← clave: baja expansión térmica
Na₂O (sodio):        0–5%     ← limitado: previene degradación
```

**Propiedades de fibra de vidrio E (estándar):**

| Propiedad | Valor |
|---|---|
| Densidad | 2.58 g/cm³ |
| Temperatura de ablandamiento | 840 °C |
| Coef. expansión térmica | 5.3 × 10⁻⁶ /°C |
| Resistencia a tensión | 3,400 MPa (muy alta) |
| Módulo elástico | 72 GPa (muy alto) |
| Resistencia química | Excelente (excepto HF) |
| Inercia a fluidos | Total (vidrio amorfo) |

**Aplicaciones ELIMFILTERS:**
- **SYNTEPORE™**: Fibra vidrio 1–10 µm para filtración de combustible
- **GASULTRA™**: Borosilicato ultrafino (<1 µm) para gases

**Ventajas de vidrio vs. polímeros:**
- No se disuelve en combustibles aromáticos
- Inerte a químicos agresivos (H₂S, ácidos)
- Temperatura de operación más alta
- Durabilidad térmica superior

**Desventajas:**
- Densidad más alta → peso aumentado
- Fragilidad a vibración extrema
- Costo más alto que polímeros

### 2.4 Carbón Activado

#### Estructura y Activación

**Materia prima:** Coco, carbón mineral, madera

```
Proceso de activación:
1. Carbonización: Precursor → Carbón puro a T > 600 °C
2. Activación física: Vapor/CO₂ a T > 800 °C
   → Abre poros, aumenta área superficial
3. Activación química: H₃PO₄ o KOH a T moderada
   → Crea porosidad adicional
```

#### Propiedades del Carbón Activado de Coco

| Propiedad | Valor | Significado |
|---|---|---|
| Área superficial BET | 900–1,200 m²/g | Ultra-alta porosidad |
| Volumen de poros | 0.4–0.6 cm³/g | Capacidad de adsorción |
| Diámetro promedio de poro | 10–25 Å (1–2.5 nm) | Microporoso |
| Densidad aparente | 0.4–0.5 g/cm³ | Ligero, bajo volumen |
| Dureza mecánica | Alto | Resiste compresión |

#### Mecanismos de Adsorción

```
1. ADSORCIÓN FÍSICA (Van der Waals):
   • Energía: 5–40 kJ/mol
   • Reversible
   • Rápida
   • Ejemplos: VOCs, olores aromáticos

2. ADSORCIÓN QUÍMICA (Chemisorption):
   • Energía: 40–400 kJ/mol
   • Irreversible
   • Lenta (requiere activación térmica)
   • Ejemplos: Gases ácidos (H₂S, SO₂), compuestos polares

3. ADSORCIÓN POR ELECTROSTÁTICA (ION EXCHANGE):
   • Grupos funcionales en carbón atraen iones específicos
   • Ejemplos: Metales pesados (Hg²⁺, Pb²⁺), colorantes
```

**Aplicación ELIMFILTERS:**
- **MICROKAPPA™** (EC1): Carbón de coco elimina VOCs (olores) y NO₂ (gases diésel)
- Capa dedicada con 25–35 g de carbón por filtro

## 3. Tratamientos Superficiales y Funcionales

### 3.1 Impregnación con Resinas

#### Resinas Fenólicas (Phenolic)

**Composición:**
```
Monómero: Fenol (C₆H₅OH) + Formaldehído (CH₂O)
Polimerización: Condensación en dos etapas (resol/novolac)
Temperatura de curado: 150–200 °C (bajo presión)
```

**Propiedades después de curado:**

| Propiedad | Valor |
|---|---|
| Densidad | 1.3–1.4 g/cm³ |
| Temperatura de transición vítrea (Tg) | 90–120 °C |
| Resistencia a tensión | 40–60 MPa |
| Resistencia química | Excelente (ácidos, álcalis) |
| Inercia térmica | Buena hasta 150 °C |
| Costo | Bajo–medio |

**Uso:** DURATECH™ — impregna celulosa técnica para control de porosidad

#### Resinas Melamínicas (Melamine)

**Composición:**
```
Monómero: Melamina (C₃H₆N₆) + Formaldehído
Polimerización: Policondensación
Temperatura de curado: 160–200 °C
```

**Ventajas sobre fenólico:**
- Mayor resistencia térmica (Tg = 130–160 °C)
- Menor amarillamiento (incoloro)
- Mayor rigidez dimensional

**Uso:** SINTRAX™ — mejor compatibilidad con aceites sintéticos

#### Resinas Epóxicas (Epoxy)

**Composición:**
```
Componente A: Bisfenol-A (BPA) + Epiclorohidrina
Componente B: Aminas alifáticas/aromáticas

Curado: A + B → Reacción exotérmica
Temperatura curado: 20–100 °C (según activador)
```

**Propiedades:**
- Resistencia adhesiva: Excelente
- Resistencia a corrosión: Superior
- Flexibilidad: Buena (menos quebradizo que fenólico)

**Uso:** MARINECLEAN™ — recubrimiento epóxico marino ISO 12944 C5-M (5 capas, 500+ µm)

### 3.2 Carga Electrostática (Electret Effect)

#### Mecanismo de Carga

```
Proceso 1 — Deposición por Corona Discharge:
  1. Electrodo negativo (-5 a -10 kV) crea plasma
  2. Fibras pasan a través del plasma
  3. Electrones se transfieren a superficie de fibra
  4. Carga negativa residual queda atrapada en material

Proceso 2 — Confinamiento en Polímero Semicristalino:
  • Carga se "congela" en capas cristalinas de polímero
  • Duración: Meses a años (dependiendo de temperatura)
  • Decaimiento gradual (sigue ley exponencial)
```

#### Distribución de Carga

```
Densidad de carga superficial: σ = 10⁻⁷ a 10⁻⁶ C/m²

Potencial eléctrico inducido: V = 100–300 V (sin contacto externo)
```

**Ventajas electrostática:**
- Atracción a partículas polares (polen, virus, polvo)
- Eficiencia mejorada 10–20% vs. sin carga
- Menor caída de presión (relajación de fuerzas mecánicas)

**Aplicaciones ELIMFILTERS:**
- **NANOFORCE™**: Nanofibra PP cargada negativamente
- **MICROKAPPA™**: Microfibra electroestática para captura de polen/bacterias

#### Degradación de Carga Electrostática

```
Causa 1 — Decaimiento temporal (normal):
  Q(t) = Q₀ × exp(-t/τ)
  
  Donde τ = constante de tiempo (semanas a meses)

Causa 2 — Humedad relativa alta (>90%):
  • Capa de agua en superficie disipa carga
  • Causa: puentes iónicos conducen electricidad
  • Efecto: pérdida en 24–48 horas si RH > 95%

Causa 3 — Temperatura elevada (>80 °C):
  • Aumenta movilidad de portadores de carga
  • Efecto: decaimiento acelerado
  • Tiempos de relajación reducidos 50–80%
```

**Implicación práctica:** MICROKAPPA™ (cabina) debe almacenarse en ambiente seco para mantener carga.

### 3.3 Tratamiento Coalescente (para separadores)

#### Química del Tratamiento Coalescente

```
Compuesto: Copolímero hidrófobo (típicamente poliuretano)
Aplicación: Revestimiento en superficie de fibra vidrio

Mecanismo:
1. Fibra desnuda (hidrofílica) → repele grasas
2. Tratamiento coalescente (hidrofóbico) → atrae grasas
3. Microgotitas de agua son rechazadas
4. Gotitas se fusionan (coalescen) en partículas mayores
5. Caen por gravedad al bowl de drenaje
```

**Parámetros de eficiencia coalescente:**

| Parámetro | Valor Típico |
|---|---|
| Ángulo de contacto agua | 100–120° (hidrofóbico) |
| Tensión superficial del medio | 20–30 mN/m (bajo) |
| Espesor del revestimiento | 1–5 µm (ultrafino) |
| Eficiencia de separación agua | 95–99% |

**Aplicaciones ELIMFILTERS:**
- **SYNTEPORE™** (combustible): Medio coalescente para biodiesel contaminado
- **AQUAGUARD™** (turbina): Medio Aquabloc® — 99% separación agua-combustible

## 4. Propiedades Mecánicas y Durabilidad

### 4.1 Resistencia Mecánica

#### Factores de Esfuerzo en el Filtro

```
Presión diferencial (mechanical stress):
  σ_mech = ΔP × d_fibra / (2 × e_fibra)
  
  Donde e_fibra = espesor de fibra

Ejemplo:
  ΔP = 5 bar = 500 kPa
  d_fibra = 20 µm
  e_fibra = 2 µm
  
  σ = (500 × 20) / (2 × 2) = 2,500 kPa = 2.5 MPa

Comparar con:
  Resistencia celulosa: ~50 MPa → Factor de seguridad = 20×
  Resistencia fibra vidrio: ~100 MPa → Factor de seguridad = 40×
```

### 4.2 Resistencia Química

#### Matriz de Compatibilidad de Materiales

| Fluido | Celulosa | PET | Poliprop. | Vidrio | Comentario |
|---|---|---|---|---|---|
| Aceite mineral 15W-40 | ✅ | ✅ | ✅ | ✅ | Compatible todos |
| Aceite sintético (PAO) | ✅ | ✅ | ✅ | ✅ | OK, pero revisar aditivos |
| Biodiesel B20 | ⚠️ | ✅ | ✅ | ✅ | Celulosa: hinchamiento posible |
| Refrigerante acuoso | ✅ | ✅ | ⚠️ | ✅ | PP: permeabilidad agua ↑ |
| Diésel ULSD | ✅ | ✅ | ✅ | ✅ | Bajo azufre, no corrosivo |
| Gasolina aromática | ⚠️ | ✅ | ✅ | ✅ | Celulosa: puede disolverse |
| Fluido hidráulico sintético | ✅ | ✅ | ⚠️ | ✅ | PP: expansión en ésteres |
| Agua desionizada pura | ⚠️ | ✅ | ✅ | ✅ | Celulosa: hinchamiento |
| AdBlue® (urea 32.5%) | ⚠️ | ✅ | ✅ | ✅ | Metales: corrosión. PP: inercia |

#### Mecanismos de Degradación

##### Disolución de Polímero
```
Ejemplo: Poliéster en gasolina aromática

Gasolina aromática contiene benceno, tolueno, xileno
Estos son solventes polares que disuelven poliéster

Resultado: Pérdida de resistencia mecánica, desprendimiento de fibras
```

##### Hinchamiento/Contracción Dimensional
```
Ejemplo: Celulosa en biodiesel B20

Biodiesel contiene metanol y glicerol
Estos alcoholes penetran la celulosa → hinchamiento
Cambio de espesor: +5 a +15%
Resultado: Cambio de caída de presión, posible colapso
```

##### Hidrolisis (Agua + Temperatura)
```
Ejemplo: Poliéster en agua caliente a >80 °C

H₂O + Poliéster [COOC] → Ácido carboxílico + Alcohol
Temperatura acelera reacción exponencialmente

Tiempo de vida media (T-50):
  T = 60 °C → τ = 5 años
  T = 80 °C → τ = 6 meses
  T = 100 °C → τ = 2 semanas
```

### 4.3 Estabilidad Térmica

#### Límites de Temperatura de Operación Continua

| Material | Tmax Continua | Tmax Pico | Razón de Límite |
|---|---|---|---|
| Celulosa | 110 °C | 140 °C | Carbonización, pérdida de resistencia |
| Poliéster (PET) | 150 °C | 170 °C | Inicio de degradación molecular |
| Polipropileno (PP) | 120 °C | 150 °C | Transición vítrea, deformación |
| Vidrio E | 240 °C | 280 °C | Matriz poliéster límite, no vidrio |
| Vidrio borosilicato | 400 °C | 500 °C | Solo material, sin matriz |

#### Envejecimiento Térm ico Acelerado

**Norma de prueba:** ASTM D2570 — Oven Aging Test

```
Procedimiento:
1. Muestra de material en horno a T = T_operación + 20–30 °C
2. Tiempo: 1,000–5,000 horas (3–6 meses de exposición acelerada)
3. Medición de resistencia residual cada 500 h
4. Criterio: Retención de ≥80% de propiedades iniciales
```

**Ejemplo de resultado:**

```
Material: Poliéster a 150 °C durante 2,000 h

Resistencia a tensión:
  Inicial:   60 MPa
  Después: 48 MPa
  Retención: 80% ✓ (PASA)

Módulo elástico:
  Inicial:   4.5 GPa
  Después:   3.8 GPa
  Retención: 84% ✓ (PASA)
```

## 5. Aglutinantes y Aditivos

### 5.1 Sistemas Aglutinantes (Binders)

#### Aglutinante Fenólico-Formaldehído

```
Reacción: Fenol + Formaldehído → Resina PF

Ventajas:
  • Bajo costo
  • Buena adhesión a celulosa/fibra vidrio
  • Resistencia química

Desventajas:
  • Emite formaldehído (VOC)
  • Límite temperatura: 150 °C
  • No apto para aplicaciones medicales
```

#### Aglutinante de Poliuretano (Polyurethane)

```
Reacción: Isocianato + Poliol → Poliuretano

Ventajas:
  • Flexibilidad superior
  • Menor temperatura curado
  • Mejor adhesión a polímeros
  • Aplicable como coalescente

Desventajas:
  • Mayor costo
  • Sensibilidad a humedad
  • Procesamiento crítico (isocianatos son tóxicos)
```

#### Aglutinante Acrílico

```
Monómero: Ácido acrílico + sales metálicas

Ventajas:
  • Bajo costo
  • Resistencia water-based (ecológico)
  • Flexible

Desventajas:
  • Resistencia térmica limitada (<80 °C)
  • No apto para aceites aromáticos
```

### 5.2 Aditivos Funcionales

#### Inhibidores de Humedad

**Propósito:** Prevenir hinchamiento de celulosa por agua

```
Mecanismo: Ocupan sitios de hidrógeno-bonding en celulosa
Evitan que agua forme puentes de H adicionales

Ejemplos:
  • Cera (wax): Barrera hidrofóbica
  • Silanos: Reaccionan con OH de celulosa
  • Plastificantes: Rellenan espacios, reducen movilidad agua
```

#### Estabilizadores UV

**Propósito:** Proteger polímeros de degradación por luz solar

```
Mecanismo: Absorción de rayos UV (280–400 nm)
Disipan energía como calor en lugar de romper enlaces C-C

Ejemplos:
  • Benzofenona: Absorción 300–350 nm
  • Hindered Amine Light Stabilizer (HALS): Regenerable
  • Carbon Black: Opacidad total, bloquer UV
```

### 6.2 Pruebas de Medio Filtrante Acabado

#### Permeabilidad (ISO 9053)

```
Equipo: Medidor de permeabilidad de aire

Procedimiento:
1. Colocar muestra bajo presión diferencial constante
2. Medir flujo volumétrico a través de la muestra
3. Calcular permeabilidad según Ley de Darcy

Resultado: Valor Gurley (tiempo para paso de aire)
  Unidad: "segundos Gurley" (s)
  Menor valor = mayor permeabilidad

Rango ELIMFILTERS:
  DURATECH™:   80–120 s
  SINTRAX™:    200–300 s
  NANOFORCE™:  800–1,200 s
```

#### Porosidad (Mercury Intrusion Porosimetry)

```
Equipo: Porosímetro de intrusión de mercurio

Principio: Mercurio (no moja) se fuerza en poros bajo presión
         Presión inversamente proporcional al tamaño de poro

Resultado: Distribución de tamaño de poro (PSD)
  Rango detectable: 0.003–300 µm
  Método no-destructivo
```

```

```
Proyecto piloto: DURATECH™-ECO

  • 100% celulosa técnica
