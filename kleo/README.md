# KLEO

Puente privado entre Telegram y Claude Code para las operaciones de
ELIMFILTERS: `Telegram -> KLEO -> Claude Code -> proyecto activo -> respuesta
por Telegram`.

- Instalación: [docs/INSTALL.md](docs/INSTALL.md)
- Comandos de Telegram: [docs/TELEGRAM_COMMANDS.md](docs/TELEGRAM_COMMANDS.md)
- Código fuente: `src/kleo/`
- Pruebas: `tests/` (`pytest`)

Ver también `.env.example` y `config/config.example.json` para la
configuración necesaria antes del primer arranque.
