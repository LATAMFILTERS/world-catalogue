---
description: Create a governed ELIMFILTERS launch/showcase package from an already-built release
---

Invoke the `elimfilters-brag` skill.

The target may be supplied after the command, for example:

`/brag /industrial-process`

`/brag latest approved Part Search release`

`/brag commit <sha>`

Rules:

1. Lock the exact release/ref before generating presentation material.
2. Reuse existing assets, screenshot/video tooling and brand governance.
3. Do not invent technical or commercial claims.
4. Do not publish or send anything automatically.
5. Produce a 15–30 second storyboard plus channel copy by default.
6. Render video only when the current environment already supports a safe render path.
7. Finish with the skill's terminal status and Ponytail completion report.
