# CROSS_REFERENCE_GOVERNANCE

## Purpose

This document defines the official governance model for cross-reference relationships inside the ELIMFILTERS ecosystem.

The objective is to prevent OEM references, competitor references, alternatives, upgrades, and equivalents from being treated as identical relationships.

This framework governs:

- PostgreSQL
- World Catalogue
- Part Search
- AI Engine
- Customer Intelligence Platform
- Equipment Search

## Core Principle

A cross reference is not automatically an equivalent.

A shared thread is not automatically an equivalent.

A shared dimension is not automatically an equivalent.

A shared application is not automatically an equivalent.

Products are considered equivalent only when:

- Fit is compatible
- Form is compatible
- Function is compatible
- Protection objective is compatible
- Operating environment is compatible

## Relationship Types

### OEM Reference

Original manufacturer reference used to identify a component.

Examples:

- Cummins
- Caterpillar
- Detroit Diesel
- Volvo
- Komatsu

OEM references are identification references.

They do not define media technology.

---

### Competitor Cross Reference

A competitor reference may indicate:

- Similar fit
- Similar form
- Similar application

It does not automatically indicate:

- Same media
- Same efficiency
- Same dirt holding capacity
- Same lifecycle

---

### ELIMFILTERS Match

Official ELIMFILTERS product selected for a protection objective.

Example:

OEM
?

Competitor
?

ELIMFILTERS SKU
?

Technology
?

Protection System

---

### Equivalent

Equivalent means:

- Same fit
- Same form
- Same function
- Same protection objective

Equivalent does not mean same brand.

---

### Alternative

Alternative means:

- Installation compatible

but may differ in:

- Media technology
- Lifecycle
- Efficiency
- Protection strategy

Alternatives must never be presented as equivalents.

---

### Technology Upgrade

A product that provides a higher protection capability than the referenced product.

Possible improvements:

- Filtration efficiency
- Water separation
- Dirt holding capacity
- Service interval
- Durability

Technology upgrades must be explicitly identified.

---

### Technology Downgrade

A product providing lower protection capability.

Downgrades should never be recommended automatically.

---

### Supersession

Official replacement path from an older product to a newer product.

---

### Obsolete

Product retained for historical lookup but not recommended for active use.

## AI Rule

The AI Engine must never say:

"This product is identical."

unless equivalency has been validated.

Preferred wording:

- Compatible replacement
- Cross-reference match
- Recommended ELIMFILTERS match
- Alternative product
- Technology upgrade
- Requires validation

## Governance Rule

Cross references are navigation.

Technology is engineering.

Asset protection is decision making.

A recommendation must satisfy all three.
