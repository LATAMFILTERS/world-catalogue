# CONFIDENCE_SCORING_STANDARD

## Purpose

Defines confidence levels used by ELIMFILTERS AI.

---

# Confidence Scale

100

OEM confirmed.

95

Multiple verified sources.

85

Manufacturer catalog validated.

75

Cross-reference validated.

65

Application match.

50

Dimensional or partial evidence.

25

Weak evidence.

0

Unknown.

---

# AI Rule

AI must disclose uncertainty when confidence is low.

---

# Governance Rule

No recommendation may be presented as certain without evidence.
