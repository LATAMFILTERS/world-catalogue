# ELIMFILTERS SEO/GEO Authority Rollout

Status: PHASE 5 ACTIVE — PHASES 1–4 FROZEN
Standard: ELIMFILTERS SEO/GEO Authority Standard v1.0

## Operating rule

Every phase follows the same loop:

GSC demand -> Authority Scorecard -> controlled remediation -> build/validators -> score delta -> merge/deploy -> GSC observation.

A page is not prioritized by score alone. Technical quality and search demand remain separate signals until the Priority Score layer combines them.

Closure rule: a phase is not frozen merely because its pages exceed the Authority-ready threshold. Target pages are driven to the maximum reasonably attainable governed score, ideally 100/100, with no measurable blockers or deficits and with build/governance validators passing.

## Phase 5 — Continuous GSC + GEO Optimization — ACTIVE

Objective: turn the Authority Standard into a permanent operating system driven by real search demand and post-release evidence.

Inputs:
- GSC queries/pages/clicks/impressions/CTR/position
- indexation and sitemap state
- Authority Scorecard
- release/build state

Outputs:
- Priority Score that keeps demand and technical authority as distinct inputs
- query-to-page ownership map
- remediation/expansion queue driven by demand rather than generic SEO activity
- Authority Score delta by release
- GSC performance delta after recrawl
- detection of new cannibalization, stale URLs and emerging query clusters

Permanent rule:
- new strategic indexable pages should score >= 80 at introduction
- target is >= 90 before being considered Authority-ready
- core strategic surfaces should be driven to the maximum reasonably attainable governed score, ideally 100/100
- critical blockers override the numeric score
- historical strategic debt is now reduced to the governed Gold Standard baseline, so regression protection can be introduced as a CI guard without freezing future content evolution
