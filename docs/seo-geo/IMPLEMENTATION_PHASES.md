# ELIMFILTERS SEO/GEO Authority Rollout

Status: ACTIVE
Standard: ELIMFILTERS SEO/GEO Authority Standard v1.0

## Operating rule

Every phase follows the same loop:

GSC demand -> Authority Scorecard -> controlled remediation -> build/validators -> score delta -> merge/deploy -> GSC observation.

A page is not prioritized by score alone. Technical quality and search demand remain separate signals until the Priority Score layer combines them.

## Phase 1 — Foundational Authority Gaps

Objective: remove structural weaknesses from the surfaces that distribute authority across the rest of the site.

Scope:
- `/knowledge-center/`
- `/systems/hydraulic/`
- `/systems/cooling-system/`
- `/systems/lubrication/`
- shared metadata/direct-answer patterns that affect these routes

Exit criteria:
- no critical blockers on target routes
- target routes >= 90 Authority Score
- unique and semantically aligned title/H1 ownership
- metadata within governed target ranges
- substantive direct answer near the top of each page
- canonical, schema and internal-link validators pass

## Phase 2 — Product Family Authority

Objective: bring weak product-family pages to a consistent technical and GEO-ready level.

Initial queue:
- coolant-filters
- hydraulic-filters
- cabin-filters
- oil-filters
- primary-air
- primary-fuel
- secondary-fuel
- air-dryer-filters
- air-cleaner-housings

Exit criteria:
- every strategic family >= 90
- explicit system/application relationship
- direct-answer opening
- intent ownership distinct from systems and technologies
- governed product/application conversion path

## Phase 3 — Industry Authority

Objective: raise all industry pages from threshold compliance to deep application authority.

Scope: all canonical ELIMFILTERS industry pages.

Target structure:
- direct technical summary
- operating environment
- critical assets
- contamination and failure mechanisms
- protection-system map
- applications by system
- selection criteria
- maintenance/reliability implications
- relevant standards and technical references
- governed next action

Exit criteria:
- all strategic industries >= 90
- indicative industry depth target met where technically justified
- no interchangeable/templated industry copy
- GSC query ownership mapped per industry

## Phase 4 — Knowledge Center Deep Authority

Objective: strengthen standards, engineering reference, glossary, diagrams and comparison intent ownership.

Priority:
- below-target standards first
- engineering-reference pages with weak depth next
- duplicate H1/title-intent clusters
- direct-answer and schema refinement

Exit criteria:
- no strategic page below 90 unless explicitly exempted
- standard/reference/engineering/glossary intents remain distinct
- evidence governance preserved
- canonical/cannibalization validator remains clean

## Phase 5 — Continuous GSC + GEO Optimization

Objective: turn the Authority Standard into a permanent operating system.

Inputs:
- GSC queries/pages/clicks/impressions/CTR/position
- indexation and sitemap state
- Authority Scorecard

Outputs:
- Priority Score
- remediation queue
- score delta by release
- GSC performance delta after recrawl

Permanent rule:
- new strategic indexable pages should score >= 80 at introduction
- target is >= 90 before being considered Authority-ready
- critical blockers override the numeric score
- once historical debt is reduced, enforce the threshold as a CI guard
