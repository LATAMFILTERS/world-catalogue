01 / PARTICLE WEAR IN BEARINGS

Hard particles trapped between moving surfaces create micro-cutting.

Silica and metal oxide particles in the 2–18µm range are the primary driver of abrasive wear. Trapped between bearing journal and race surfaces at operating clearances of 5–15µm, hard particles cut micro-grooves into precision surfaces. Each pass increases roughness. Roughness increases wear rate. Wear increases particle generation — a self-amplifying failure chain.

Bearing clearance reduction follows a measurable progression: initial wear debris (ISO 4406 code shift from 16/14/11 to 20/18/15) accelerates journal contact. Localized temperature spikes exceed 180°C. Oil film collapse. Seizure.

Failure interval: 2,000–3,000 hrs (vs. 15,000+ hrs optimal)

Bearing replacement cost: $8,000–$45,000 per event

03 / PROPORTIONAL VALVE FAILURE

Particle contamination jams precision spool clearances of 5–10µm.

Proportional hydraulic valves operate at internal clearances of 5–10µm. A single hard particle within this range — silica, metal oxide, or wear debris — causes spool stiction. The valve no longer responds proportionally to command signals. Machine functions become unpredictable. In mobile equipment, this creates load handling failures.

ISO 4406 cleanliness target for proportional valves: 16/14/11. Any system operating above this code requires immediate filter system review. Above 19/17/15: valve failure risk becomes statistically certain within 500 operating hours.

Valve response deviation: >15% from command signal

Valve replacement + downtime: $12,000–$80,000 per incident
