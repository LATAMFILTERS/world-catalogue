PREMIUM UX LAYER

Visual Concepts for Design Evaluation

READY FOR REVIEW

Six browser-rendered mockups covering the complete ELIMFILTERS® website experience. Each shows BEFORE vs. AFTER the Premium UX Layer. Open any mockup in a browser — no server required, all self-contained HTML.

// Viewing Instructions
Desktop Viewing
  1. Download all files to the same folder
  2. Open any .html file directly in Chrome, Firefox, or Safari
  3. View at 1400px+ window width for optimal layout
  4. All animations trigger on page load — refresh to replay
  5. Each file is self-contained — no internet required after loading (except Google Fonts)
Best experienced in Chrome or Firefox. Some CSS animations may render differently in Safari.
Mobile Viewing
  1. Send any .html file to your phone (AirDrop, email, WhatsApp)
  2. Open in mobile browser (Chrome for Android / Safari for iOS)
  3. Each mockup includes a 375px mobile comparison panel
  4. Or: host locally with npx serve . -l 3000 and open on device
Mobile panels show the 375px viewport — the experience is best evaluated on an actual iPhone or Android device at that width.

Homepage First Impression
"ENGINE FILTRATION" headline over dark gradient. Functional, informative.
"PROTECTING INDUSTRIAL ASSETS" over ambient mining scene with CSS dust particles. Brand claim visible before any reading.
Problem Communication
Text + mechanic image. "What you can't see is stopping your fleet."
Pinned scroll section: 3 failure modes reveal sequentially. Bearing wear, injector stiction, valve failure — animated, not described.
Statistics
Animated counters. Numbers visible.
Numbers + context lines. "+45%" becomes "8,000 → 11,600+ hours per overhaul cycle."
Technology Pages
Comparison table. Spec-sheet format.
Horizontal scroll gallery + particle capture SVG animation + ISO 16889 performance curve. Engineering communication, not spec listing.
Industry Pages
12 identical CategoryPage templates. Different words, same layout.
Industry-specific ambient overlays. Mining: silica dust particles + Mohs hardness comparison. Each industry feels designed for that buyer.
Knowledge System
Plain numbered sections. Information-dense, experience-thin.
Section progress rail (01–08). Inline yellow metric highlights. Pullquote blocks. Network graph on hub.
Distributor Entry Point
Direct to form. Cold.
Territory flyout: Colombia/Mexico/Chile/Peru/Ecuador availability confirmed before form. Reduces abandonment.
Mobile Experience
Responsive (desktop shrunk). Works, not designed for mobile.
Portrait hero crop, 2x2 stat grid with context lines, particle animations sized for mobile.
Visual Language
Yellow accents on black. Professional.
Yellow = protection (capture flash on filter animation). Red = failure. Color carries meaning, not just aesthetic.
Emotional Register
"Well-built industrial website."
"Engineering company with a point of view."
